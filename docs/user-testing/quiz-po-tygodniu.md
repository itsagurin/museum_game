# Quiz po tygodniu

Moderator przygotowuje pięć pytań z listy dzieł rzeczywiście odnowionych przez daną osobę, zapisanej w arkuszu. Nie dodawaj dzieł jedynie oglądanych. Wybierz wpisy z `content/artworks.json`, a klucz odpowiedzi uzgodnij z recenzentem — nie traktuj statusu `unverified` jako potwierdzonej wiedzy. Zapisz wersję manifestu i ID użytych dzieł. Pytania wyślij lub zadaj po 7 dniach (okno ±1 dzień), wyłącznie zgodnie z osobną zgodą na kontakt.

Kod badania: [____]. Odnowione ID: [____]. Data pierwszej sesji i quizu: [____]. Wersja / recenzent klucza: [____]. Nie otwieraj gry przed odpowiedzią; przy braku pamięci odpowiedz „nie pamiętam”.

1. Pokaż miniaturę pierwszego odnowionego dzieła bez podpisu. „Jak nazywa się autor?”
2. Dla tego samego dzieła: „Jaki tytuł lub temat obrazu pamiętasz?”
3. „Jaką ciekawostkę o tym dziele pamiętasz? Opowiedz własnymi słowami.”
4. Jeśli odnowiono kolejne dzieło, pokaż jego miniaturę: „Kto jest autorem?”. Przy jednym dziele zapytaj o epokę pierwszego obrazu.
5. „Jaki szczegół lub historię z odnowionych dzieł pamiętasz po tygodniu?”. Przy kilku dziełach wskaż inne niż użyte w pytaniu 3; przy jednym poproś o drugi szczegół z zaakceptowanego opisu.

Klucz generowany z użytych wpisów: [ID → autor / tytuł / epoka / zaakceptowane fakty ____]. Odpowiedzi na 1, 2 i 4 oceniaj 0/1; 3 i 5 po 0/1 za trafny fakt lub wierną parafrazę, bez wymagania dosłownego cytatu. Nie karz za wariant pisowni nazwiska, jeśli identyfikacja jest jednoznaczna. Przy tym samym fakcie w 3 i 5 punkt przyznaj tylko raz. Jeśli drugiego niezależnego faktu nie można zapytać, oznacz 5 jako niedostępne i podaj mniejszy mianownik.

Metryka planu „ciekawostka po tygodniu”: odsetek uczestników przypominających co najmniej jeden zaakceptowany fakt w 3 lub 5; cel ≥50%. Oddzielnie raportuj autora i ogólną liczbę punktów. Nie utożsamiaj pięciu pytań z pięcioma niezależnymi osobami.
