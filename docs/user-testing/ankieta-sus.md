# Ankieta SUS po sesji

Kod badania: [____]. Odpowiadaj po wykonaniu zadań, bez pomocy moderatora. Zaznacz jedną liczbę dla każdego zdania: 1 = zdecydowanie się nie zgadzam, 2 = raczej się nie zgadzam, 3 = ani się zgadzam, ani nie zgadzam, 4 = raczej się zgadzam, 5 = zdecydowanie się zgadzam.

1. Chcę często korzystać z tej gry. [1 / 2 / 3 / 4 / 5]
2. Gra jest niepotrzebnie skomplikowana. [1 / 2 / 3 / 4 / 5]
3. Gra jest łatwa w obsłudze. [1 / 2 / 3 / 4 / 5]
4. Do korzystania z gry potrzebuję wsparcia osoby technicznej. [1 / 2 / 3 / 4 / 5]
5. Różne funkcje gry dobrze ze sobą współpracują. [1 / 2 / 3 / 4 / 5]
6. W grze jest zbyt dużo niespójności. [1 / 2 / 3 / 4 / 5]
7. Większość osób nauczyłaby się korzystać z gry bardzo szybko. [1 / 2 / 3 / 4 / 5]
8. Korzystanie z gry jest bardzo uciążliwe. [1 / 2 / 3 / 4 / 5]
9. Korzystając z gry, czuję się pewnie. [1 / 2 / 3 / 4 / 5]
10. Przed rozpoczęciem korzystania z gry muszę się wiele nauczyć. [1 / 2 / 3 / 4 / 5]

Liczenie wyniku przez zespół: dla pozycji nieparzystych od odpowiedzi odejmij 1; dla parzystych odejmij odpowiedź od 5. Zsumuj dziesięć wartości i pomnóż przez 2,5. Zakres wynosi 0–100. Przykład: dziesięć odpowiedzi „3” daje 50. Wynik nie jest procentem poprawnych odpowiedzi. Brak odpowiedzi oznacz jako brak kompletu; nie dopisuj wartości za uczestnika. Raportuj medianę, zakres oraz liczbę pełnych ankiet; przy 5–8 osobach unikaj pozornej precyzji.

Źródło: John Brooke, System Usability Scale (SUS), 1986/1996; [oryginalny artykuł autora „SUS — a quick and dirty usability scale”](https://www.researchgate.net/publication/319394819_SUS_--_a_quick_and_dirty_usability_scale). Powyżej znajduje się robocze polskie sformułowanie do pilotażu, bez deklaracji walidacji psychometrycznej polskiego tłumaczenia. Stosuj tę samą wersję pytań we wszystkich sesjach danego badania.
