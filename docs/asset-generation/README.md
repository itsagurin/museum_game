# Osobne assety PNG

25 samodzielnych grafik RGBA przygotowanych narzędziem imagegen z dostarczonych arkuszy. Zasłonięte fragmenty zostały odtworzone, a meble mają puste blaty i kompletne nogi. To rekonstrukcje przedmiotów z referencji, nie wyłącznie prostokątne kadry źródłowych pikseli.

- `img/romantyzm_assets/`: 13 plików PNG.
- `img/mloda_polska_assets/`: 12 plików PNG.
- `output/asset-previews/`: podglądy obu zestawów na jasnym tle.
- `output/romantyzm-mloda-polska-assets.zip`: oba foldery i manifest.

Pełny zestaw promptów, korekty i rozmiary znajdują się w [individual-assets.json](./individual-assets.json).

Każdy finalny PNG został odczytany i sprawdzony: posiada kanał alfa, przezroczyste piksele tła oraz margines między widocznym przedmiotem i krawędzią kadru. Pliki PNG zachowują przezroczystość; jasne tło występuje wyłącznie w podglądach JPG.

Pianino i stołek są oddzielne. Skrzypce, smyczek, pusty futerał i podstawa są oddzielne. Stół nie zawiera drobnych przedmiotów ani książek. Kałamarz i pióro są oddzielne. Pulpit nie zawiera kartki z nutami. Każdy obraz pozostaje jednym assetem razem z ramą. Małe zestawy książek i związane pakiety listów pozostają grupami.
