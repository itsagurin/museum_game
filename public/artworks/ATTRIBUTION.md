# Artwork sources

Local WebP reproductions, resized for this demo. Original works and reproductions are marked public domain on Wikimedia Commons.

- Stańczyk, Jan Matejko, 1862: https://commons.wikimedia.org/wiki/File:Jan_Matejko,_Sta%C5%84czyk.jpg
- Bociany, Józef Chełmoński, 1900: https://commons.wikimedia.org/wiki/File:J%C3%B3zef_Che%C5%82mo%C5%84ski_-_Bociany_-_01_(MP_561_MNW).jpg
- Konstytucja 3 maja, Jan Matejko, 1891: https://commons.wikimedia.org/wiki/File:Konstytucja_3_Maja_1791.jpg

The JSON grids simplify these reproductions into five curated colors. The renderer draws each grid cell as a separate square with its palette hex; it never overlays the source photograph. Unpainted pixels show a pale color hint and matching paint restores full palette color. This is a low-resolution stylization, not historical annotation or semantic object segmentation.
